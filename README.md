Sizzle & Serve — Bistro Rush: a one-chef kitchen scramble. Orders land on the board, you grab ingredients from the crates, chop vegetables, grill patties, stack dishes on a plate at the Assembly Counter and serve them before patience runs out. Fast serves earn tips, combos pay extra, and the rush hour never lets up. A complete, original cooking game that plays offline in a desktop browser from static files — keyboard and mouse, no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and press Enter to start the day. Move with WASD / arrow keys or click to walk, E to use a station (hold E to chop), Q to bin what you are holding.
